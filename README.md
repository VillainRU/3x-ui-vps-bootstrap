# 3x-ui VPS Bootstrap

Интерактивная начальная настройка чистого Ubuntu/Debian VPS под 3x-ui.

## Запуск одной строкой

Подключитесь к серверу по SSH под `root` и вставьте:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/VillainRU/3x-ui-vps-bootstrap/main/install.sh)
```

Если вход выполнен не под root:

```bash
sudo bash -c 'exec bash <(curl -fsSL https://raw.githubusercontent.com/VillainRU/3x-ui-vps-bootstrap/main/install.sh)'
```

Process substitution здесь важен: скрипт задаёт вопросы и должен читать ответы из текущего SSH-терминала. Вариант `curl URL | bash` для этого сценария не используйте.

> Репозиторий сейчас Private для тестирования. Неавторизованный серверный `curl` не сможет скачать Private raw-файл. Для one-line теста временно переключите репозиторий в Public; для приватной установки используйте авторизованный GitHub-доступ (например, deploy key или `gh`). Не вставляйте PAT-токен прямо в команду.

## Что делает скрипт

- создаёт нового или переиспользует указанного Linux-пользователя и добавляет его в `sudo`;
- устанавливает пароль пользователя и принимает одну строку публичного SSH-ключа;
- для существующего пользователя сохраняет уже имеющиеся ключи и добавляет новый;
- показывает, где взять `.pub`-ключ в Windows и Linux;
- устанавливает официальный 3x-ui в SQLite-режиме и умеет продолжить настройку после частичного сбоя предыдущего запуска;
- задаёт имя и пароль панели, выбранный порт и случайный WebBasePath;
- привязывает административную панель к `127.0.0.1`, поэтому она не доступна напрямую из интернета;
- меняет SSH-порт, отключает root-вход, парольную и keyboard-interactive аутентификацию;
- учитывает Ubuntu/Debian `ssh.socket`, если он используется;
- проверяет `sshd -t`, эффективные SSH-параметры и наличие нового слушателя;
- не закрывает текущий сеанс и требует подтвердить успешный вход из второго терминала;
- при ошибке после изменения SSH удаляет только созданные этим запуском drop-in-файлы и пытается вернуть прежний SSH-доступ;
- выводит `ssh://`-ссылку, команду туннеля, локальный URL панели и данные 3x-ui;
- сохраняет итоговые параметры только root в `/root/3x-ui-vps-install-result.env` с правами `600`.

Скрипт не удаляет автоматически пользователя и уже установленную панель при ошибке: это оставляет данные доступными для диагностики и позволяет продолжить частичный запуск с тем же пользователем.

## После завершения

1. В отдельном терминале выполните предложенную команду проверки SSH.
2. Только после успешного входа подтвердите `YES` в первом терминале.
3. На своём компьютере запустите предложенную команду SSH-туннеля.
4. Откройте локальный адрес панели, который выведет скрипт.
5. После создания подключения и получения ссылки вида `vless://...`, если в ней есть `localhost`, замените `localhost` на публичный IP-адрес сервера.

## Важные ограничения

- Перед запуском проверьте, что новый SSH-порт разрешён в security group/сетевом firewall провайдера. UFW и firewalld скрипт пытается обновить автоматически.
- Скрипт предназначен для чистого VPS и останавливается при сторонней существующей установке `/usr/local/x-ui/x-ui`; установку после незавершённого запуска этого скрипта он продолжает при наличии `/var/log/3x-ui-vps-bootstrap-install.log`.
- Loopback-ограничение касается административной панели. VLESS-inbounds и отдельный subscription listener 3x-ui — другие сетевые слушатели; их правила скрипт не меняет.
- Панель работает по HTTP только внутри SSH-туннеля. Не публикуйте её порт наружу и не используйте прямой публичный URL.
- Для панели выбирайте свободный порт в диапазоне `1024–65535`; скрипт дополнительно проверяет занятость порта на VPS.
- Локальный порт SSH-туннеля по умолчанию — `18080`; он специально не совпадает с портом панели на VPS и не требует прав root.
- Перед использованием просмотрите исходник и зафиксируйте commit, если нужна полностью воспроизводимая установка вместо текущей upstream-версии.

Установщик 3x-ui загружается из официального репозитория [MHSanaei/3x-ui](https://github.com/MHSanaei/3x-ui). Для этого проекта используется документированный режим `XUI_NONINTERACTIVE=1`, после чего скрипт явно задаёт нужные параметры панели и loopback-привязку.
